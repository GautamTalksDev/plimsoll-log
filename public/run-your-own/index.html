Run your own log

Anyone can run plimsolld. Verification uses plimsoll verify --log <url>, not our database.

plimsolld -addr :8080 -db ./log.sqlite -key ./log-signing.key

The log is a public git repository. Anyone can clone it, replay every Merkle leaf and signature offline, and detect a rewritten history — no trust in this operator required. Verification works against any conforming log, not only this one.
